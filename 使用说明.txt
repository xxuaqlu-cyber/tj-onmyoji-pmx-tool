阴阳师 PMX 一键解包工具（精简版）

资源拉取
1. 双击“拉取更新.bat”打开可视化拉取工具。
2. 选择 MuMu 模拟器目录后，点击“检测设备”，工具会列出正在运行的实例；选择实例后会自动使用对应的 ADB，并自动查找阴阳师目录。
3. ADB 程序、设备地址、Android 源目录和本地保存目录仍可在窗口中手动修改。
4. 本地保存目录默认是工具旁的 yys，也可点击“选择…”改到其他目录。
5. 先点击“连接并检测”。首次下载或修复资源用“完整拉取全部资源”，游戏日常更新后用“增量拉取更新”。
6. 增量模式只下载新增、变化、本地缺失或大小不符的文件；远端已删除的本地文件会保留。
7. 点击“更新项目”可从 GitHub 拉取最新代码；更新成功后会自动重启工具。
8. 设置只保存在本机，不写死在脚本中。

启动
1. 双击“启动带骨模型工具.bat”。
2. 阴阳师目录选择完整 yys，也可选择 cloudfilesys3\res。
3. 输出目录默认是工具旁的 rigged_models。

主工具保留四个功能

一、一键解包 PMX 白模
- 增量读取 model.idx / model*.wpk，并复用 unpacked 中已有内容。
- 同时收集 model、热更新散文件、temp_cache\res.zip，以及 fx_model、
  levelsets、static、fx、res 中可转换的带骨模型和静态道具。
- 只转换模型、骨骼、权重与 UV，不分析材质或解码贴图。
- 输出：rigged_models\PMX白模\<大小分桶>\<模型目录>
- 清单：rigged_models\PMX白模\白模清单.csv
- 每个目录带 .build.json；资源未变化时直接复用，不重复生成。

二、一键解包带贴图 PMX
- 在白模所需模型资源基础上继续读取 THX/THP、APK 与各资源包材质依赖。
- 只在逻辑路径、材质、贴图实体能够闭环时绑定主贴图，不猜贴图。
- 确认属于同一角色且位置、骨架验证通过的附件直接并入主体。
- 带贴图输出按角色整理：
  rigged_models\PMX输出\带贴图\按角色\<角色>\<大小分桶>\<模型目录>
- 未找到可靠贴图的结果：
  rigged_models\PMX输出\未匹配贴图\<大小分桶>\<模型目录>
- 构建指纹跨目录判重；人工移动分类后再次解包仍会复用现有 PMX。

三、解包带贴图场景 PMX
- 增量读取 scene 场景描述，并显示可搜索、多选的场景清单。
- 按 SCN 保存的位置、旋转、缩放还原模型摆放；ComponentGroup 会合成父级变换。
- 通过 THX 精确补取 GIM、Mesh、MaterialGroup 和 KTX，不靠近邻文件猜资源。
- 大场景自动拆成共享同一坐标原点的多个 PMX。
- 输出：rigged_models\场景PMX\<场景目录>
- 每个场景同时保存 场景布局.json、缺失资源.csv 和 .build.json。
- 水面、粒子、动态植被、实时灯光和游戏专用 Shader 不属于 PMX 可完整承载的内容。

四、安装依赖
- 安装/升级 pymeshio、Pillow、ASTC 解码、cryptography、zstandard、
  numpy 和 moderngl。
- 首次使用或出现缺少模块提示时点击一次即可。

PMX 预览器
- 双击“启动PMX预览器.bat”。
- 点击顶部“场景目录”可直接切换到 rigged_models\场景PMX，并自动选择“场景 PMX”范围。
- 也可以在“范围”下拉框中选择“场景 PMX”；列表统一显示为“其他资源 / 场景”。
- 黑底、无光照原色贴图预览；左拖旋转，右拖/中拖/Shift+左拖平移，
  滚轮缩放，双击重置。
- 支持新到旧、旧到新、角色、名称和源大小排序，以及角色筛选。
- 列表右键：
  1. “移动到其他角色分类…”：移动整个模型目录，同步规则、分类清单与报告路径；
  2. “导出本模型文件夹…”：连同 PMX、贴图和构建信息复制到指定目录；随后可选择保持默认格式，或额外生成无压缩 DDS 贴图（原 PNG 保留，PMX 仍引用 PNG）；
  3. “导出到上次选择目录”：连续快速导出多个模型。
- 同名导出目录自动加 _2、_3，不覆盖已有文件。

式神动作工具
- 双击“启动式神动作工具.bat”。
- 动作目录默认是 unpacked\model；点击“扫描动作”后可按动作名或骨架名筛选。
- 也可点击“打开单个动作”，直接载入一个 .rawanimation。
- 选择配套 PMX 后显示模型蒙皮动画；未选择 PMX 或显卡不支持时显示骨架动画。
- 中间的 PMX 模型列与 PMX 预览器使用同一套范围、稀有度、角色、搜索和排序规则，单击模型即可套入当前动作。
- 载入动作后会自动按角色族筛选 PMX；点击“匹配当前动作”会优先套入同角色的最高匹配形态，其余同角色形态标为“候选”。
- 同角色不同形态骨长、Bind 姿势或附加骨数量不一致时，会启用形态重定向，保留目标 PMX 自身骨架，只施加动作的局部变化。
- 形态骨架有前缀、展示后缀或少量改名时，会尝试唯一骨名别名映射；有歧义的别名不会强行绑定。
- 套模会优先读取同名 Skeleton 的精确绑定姿势，再应用相对骨骼变化；只有缺少绑定数据时才退回动作首帧。
- 相机目标、特效挂点等突然远离主体的辅助骨会从预览取景中隔离，原始动作数据不会被改写。
- 预览支持播放、暂停、循环、倍速和时间轴；左键拖动旋转，滚轮缩放。
- 导出时选择与动作配套的 PMX，再点击“导出 VMD”。
- 程序会同时生成“_动作兼容.pmx”，用于解决 VMD 骨名最多 15 字节的限制；原 PMX 不会修改。
- VMD 没有骨骼缩放通道。源动作含缩放时仍可在预览器中查看，但导出的 VMD 会省略缩放并显示提醒。
- 当前支持绝大多数 RAWANIMA v0；少量 v1 会跳过并计入扫描结果。

数据目录
- yys：游戏资源，只读。
- unpacked：增量解包与贴图缓存，不要手动清空。
- rigged_models：白模、带贴图 PMX、报告与角色分类规则。
- APK 是基础模型资源补充来源；已有缓存可以长期复用。

贴图格式
- Android 版原始贴图保存在 unpacked 的 .ktx 文件中；当前资源实际使用 ASTC/KTX，不是 DDS。
- PMX 输出目录中的 .png 是从原始 KTX 解码得到的通用贴图，像素不会再次有损，但不保留 ASTC 压缩数据和全部 mip 层级。
- 需要归档或继续研究游戏原始资产时保留 .ktx；需要 MMD、Blender 等软件直接加载时使用 .png。不要把 KTX 统一转成 DDS，除非已确认目标平台和压缩格式可无损对应。

说明
- 所有解包功能都不会向游戏目录写文件。
- 已有 unpacked、PMX 和 PNG 会尽量增量复用。
- “未匹配贴图”表示依赖缺失或有歧义，程序不会强行乱贴。
